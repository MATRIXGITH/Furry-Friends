Welcome to my website, FURRY FRIENDS.

Furry Friends is a responsive pet care website developed as part of the TU Dublin Web Development assessment.

The website provides helpful information, advice and services for pet owners, with a focus on dog care, training and accommodation.
Its purpose is to create a friendly, accessible and informative online experience for pet owners.

LIVE WEBSITE

https://matrixgith.github.io/Furry-Friends/

WEBSITE FEATURES
- Responsive navigation bar with dropdown menu.
- Multiple informational pages covering pet care and services.
- Dog training and Doggy Hotel information.
- Image gallery showcasing pets.
- Testimonials and helpful pet care tips.
- Contact and enquiry form with validation.
- Responsive layouts for different screen sizes.
- Social media links in the footer.
- Consistent colour palette and typography throughout the website.
TECHNOLOGIES USED
- HTML5 – Website structure and content.
- CSS3 – Styling, layouts and responsive design.
- Bootstrap 5 – Responsive components and grid system.
- JavaScript – Form validation and interactive elements..
- GitHub Pages – Website deployment.
